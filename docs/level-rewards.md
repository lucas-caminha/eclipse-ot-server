# Level Rewards

New characters start at level 20 with the configured first-items kit in
`data/scripts/creaturescripts/player/send_first_items.lua`.

From level 40 through level 200, the `LevelRewards` creature event grants
vocation-specific equipment milestones. Rewards are delivered to the Store Inbox
once per character using player KV keys under `level-rewards`.

After level 200, rewards should move away from power equipment and toward
cosmetics, mounts, outfits, addons, money, tokens, and other account-friendly
prizes.
