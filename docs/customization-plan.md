# Customization Plan

Eclipse OT direction:

- Brazilian PvP audience
- Medium/high rates
- Long-term progression
- Boss gate progression
- Custom content with clear tiers
- Avoid chaotic one-off edits; document custom systems as they are added

## First Feature Candidate: Boss Teleport Room

Suggested structure:

- Central TP room
- Boss tiers: early, mid, endgame
- Level requirements
- Storage/cooldown checks
- Clear messages on enter/blocked
- Reward documentation

Suggested folders for future custom work:

```text
data-custom/
  bosses/
  teleport-room/
  quests/
  npcs/
  movements/
  actions/
  creaturescripts/
  globalevents/
```
